A short, judge-directed entry: a text about bringing donuts became a
promise to bring donkeys, and now four donkeys are in the parking lot
while HR wants a word.

## The entry

**Texted my boss I would bring the donuts — autocorrect sent I would bring the donkeys. There are now four donkeys in the parking lot, and HR wants a word.**

## How it works

`main.py` writes the entry text to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when set). No network, no randomness, no
arguments: the entry is fixed, so every run produces the same bytes.
